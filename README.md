# Family Cinéma — page d'accueil

Intégration en HTML / CSS / JavaScript simple de la maquette Figma « Family cinema ».

## Lancer la page

Ouvre `index.html` dans ton navigateur (double-clic). Rien à installer.

## Fichiers

- `index.html` — le contenu de la page
- `style.css` — la mise en forme (couleurs de la maquette en haut du fichier)
- `script.js` — les interactions : carrousel, slider « À l'affiche », choix du jour, « voir plus de films », menu mobile
- `images/` — les images (voir `images/LISEZMOI.md` pour la liste à exporter depuis Figma)
